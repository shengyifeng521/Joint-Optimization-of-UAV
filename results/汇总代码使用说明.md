# 实验结果 JSON 批量汇总

Python 脚本 `summarize_results.py` 读取已有实验结果 JSON，匹配原始实例 JSON，导出 XLSX。不会重新调用求解器。

## 运行

首次安装依赖：

```sh
python3 -m pip install openpyxl
```

在脚本所在目录运行（Python 3）：

```sh
python3 summarize_results.py data --instance-dir 原始实例目录 -o summary.xlsx
```

这里 `data` 是**存放实验结果 JSON 的目录**。若 `data` 存放原始实例，应将第一个参数改成实际的结果目录。

针对本次提供的结果：

```sh
python3 summarize_results.py "/Users/syf/Desktop/最新进展/要用的数据/解/branch" \
  --instance-dir "/Users/syf/Desktop/最新进展/要用的数据/data" \
  -o branch_summary.xlsx
```

省略 `--instance-dir` 时，从每个结果文件的目录逐级向上查找最近的 `data/实例名.json`。推荐显式指定，以免不同规模的同名实例混淆。

加 `-r` 可递归遍历结果目录。递归时实例名带相对子目录，例如 `branch/115`，用于区分不同算法。支持去掉结果文件名的 `joint_`、`two_step_`、`sga_` 前缀，其余实例名原样保留。

```sh
python3 summarize_results.py "/Users/syf/Desktop/最新进展/要用的数据/解" \
  --instance-dir "/Users/syf/Desktop/最新进展/要用的数据/data" -r -o all_summary.xlsx
```

可选 `--report report.json` 保存数据来源和异常记录。

## 列的含义

| 列 | 来源或计算方式 |
| --- | --- |
| 实例名 | 结果文件名去扩展名和已知前缀 |
| 视点数 | 原始实例 `view_points` 长度，缺失时用 `metadata.num_view_points` |
| 采样点数 | 原始实例 `sample_points` 长度，缺失时用 `metadata.num_samples_points` |
| S1 obj | `-quality_norm + photo_norm` |
| S2 obj | `energy_norm` |
| total obj | `S1 obj + S2 obj`，不直接复制原 JSON 的 `obj` |
| runtime | 结果的 `runtime`，本次结果单位为秒，保留总运行时间 |
| 选择的视点数量 | `selected_vps` 长度，其次 `selected_vp_ids` 长度，再其次 `n_viewpoints` |
| 拍照数量 | `photos`，缺失时用 `selected_pairs` 或 `selected_photos_readable` 长度 |
| 求解状态status | 结果的 `status`，保留原始编码 |

缺失项留空并输出警告，真实的 0 会保留。无解或字段不全的结果仍保留已有信息；损坏的 JSON 和配置文件跳过并输出原因。目标值保留完整数值精度，XLSX 显示 6 位小数，runtime 显示 3 位小数。

## 依赖

仅依赖 Python 3 和 `openpyxl`，无需 Node.js 或 Codex 专用依赖。

本次附带的汇总表来源为 `要用的数据/解/branch` 的 18 个结果，规模来自同级项目的 `data` 目录。实例 115：112 个候选视点、79 个采样点、34 个已选视点、58 张照片。
